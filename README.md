# イベント・チケット予約管理システム

ASP.NET Core Razor Pages + MySQL で開発したイベント検索・申込・予約管理 Web アプリケーションです。

## 概要

一般利用者は開催予定イベントの検索・詳細確認・チケット予約・予約確認を行い、管理者はイベント情報や予約状況を管理します。

## 実装機能

### 一般利用者
- トップページ（開催予定イベント一覧）
- イベント検索（イベント名・カテゴリ・開催日・会場、2種類以上組み合わせ可）
- イベント詳細表示（残席数含む）
- チケット予約（予約枚数入力、サーバー側金額計算）
- 予約完了画面（予約番号表示）
- 自分の予約一覧表示
- 予約キャンセル（開催前かつ予約済の場合のみ）

### 管理者
- イベント管理（一覧・編集・詳細・公開停止・削除）
- イベント登録
- イベント編集
- 予約管理（検索・状態変更）
- 売上集計・人気イベントランキング（加点機能）

## 技術スタック

- フレームワーク: ASP.NET Core Razor Pages (.NET 10)
- 言語: C# / HTML / CSS / Bootstrap
- DB: MySQL 8.x
- DB接続: MySqlConnector（パラメータ化クエリ使用）

## 起動方法

1. .NET 10 SDK をインストール
2. MySQL に `setup.sql` を実行して DB を作成
3. `appsettings.json` の接続文字列を環境に合わせて設定
4. プロジェクトフォルダで `dotnet run`
5. ブラウザで `http://localhost:5000` (または表示された URL) にアクセス

## DB 設定

- データベース名: `event_system`
- 接続文字列（例）: `Server=localhost;Port=3306;Database=event_system;Uid=root;Pwd=...;Charset=utf8mb4;`
- 共有サーバー: `172.16.2.26` (MySQL root password は担当者に確認)

## 入力チェック

- イベント登録: イベント名必須、開催日時必須、会場必須、料金 0円以上、定員 1以上
- 予約: 利用者必須、イベント必須、予約枚数 1以上、残席以下
- オーバーブッキング禁止（残席超過時はエラーメッセージ表示）
- 合計金額はサーバー側で計算（クライアント入力禁止）
- SQL インジェクション対策: パラメータ化クエリ使用

## 削除方針

イベントは完全削除または公開停止（論理削除）の両方に対応。公開停止時はステータスを「公開停止」に変更。

## 予約番号

形式: `RYYYYMMDD####`（例: R202611050001）、重複なし。
